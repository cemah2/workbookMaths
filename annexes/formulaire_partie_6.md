## Partie VI · Génératif et RL

### M25a · Gaussienne multivariée, conditionnement et divergence KL

Vecteurs en colonne ($d$ coordonnées) ; plusieurs vecteurs : les lignes d'un tableau $(n, d)$, comme NumPy et `mymath`. $\boldsymbol{\Sigma}$ symétrique définie positive, $\boldsymbol{\Sigma} = \mathbf{L}\mathbf{L}^\top$ (Cholesky, $\mathbf{L}$ triangulaire inférieure), $\boldsymbol{\Sigma} = \mathbf{Q}\operatorname{diag}(\lambda_1, \ldots, \lambda_d)\mathbf{Q}^\top$ ; $\Delta$ distance de Mahalanobis ; $\boldsymbol{\Lambda} = \boldsymbol{\Sigma}^{-1}$ précision ; blocs $a$, $b$ ; $\boldsymbol{\varepsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$ ; KL et entropies en nats.

| matrice de précision | $\boldsymbol{\Lambda} = \boldsymbol{\Sigma}^{-1}$ : $\boldsymbol{\Sigma} _{a \mid b} = \boldsymbol{\Lambda} _{aa}^{-1}$, $\boldsymbol{\mu} _{a \mid b} = \boldsymbol{\mu} _a - \boldsymbol{\Lambda} _{aa}^{-1}\boldsymbol{\Lambda} _{ab}(\mathbf{x} _b - \boldsymbol{\mu} _b)$ ; sachant toutes les autres coordonnées, $\mathbb{V}(x_i \mid \ldots) = \frac{1}{\Lambda _{ii}}$ ; $i \ne j$ : $\Lambda  _{ij} = 0 \iff$ $x_i$ et $x_j$ indépendantes sachant les autres ($\Sigma _{ij} = 0$ : indépendantes tout court) |
| produit de deux densités | $d = 1$ : $\frac{1}{\sigma_3^2} = \frac{1}{\sigma_1^2} + \frac{1}{\sigma_2^2}$, $\frac{\mu_3}{\sigma_3^2} = \frac{\mu_1}{\sigma_1^2} + \frac{\mu_2}{\sigma_2^2}$ ; $\mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_1, \boldsymbol{\Sigma}_1)\thinspace\mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_2, \boldsymbol{\Sigma}_2) = \kappa\thinspace\mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_3, \boldsymbol{\Sigma}_3)$, $\boldsymbol{\Sigma}_3^{-1} = \boldsymbol{\Sigma}_1^{-1} + \boldsymbol{\Sigma}_2^{-1}$, $\boldsymbol{\mu}_3 = \boldsymbol{\Sigma}_3(\boldsymbol{\Sigma}_1^{-1}\boldsymbol{\mu}_1 + \boldsymbol{\Sigma}_2^{-1}\boldsymbol{\mu}_2)$, $\kappa = \mathcal{N}(\boldsymbol{\mu}_1 \mid \boldsymbol{\mu}_2, \boldsymbol{\Sigma}_1 + \boldsymbol{\Sigma}_2)$ (MML §6.5.2) ; $\mathcal{N}(y \mid x, \sigma^2) = \mathcal{N}(x \mid y, \sigma^2)$ |
| modèle linéaire gaussien | $\mathbf{x} \sim \mathcal{N}(\mathbf{m}, \mathbf{V})$, $\mathbf{y} = \mathbf{A}\mathbf{x} + \mathbf{b} + \mathbf{w}$, $\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \mathbf{R})$ indépendant : $`\begin{pmatrix} \mathbf{x} \cr \mathbf{y} \end{pmatrix} \sim \mathcal{N}\Big(\begin{pmatrix} \mathbf{m} \cr \mathbf{A}\mathbf{m} + \mathbf{b} \end{pmatrix}, \begin{pmatrix} \mathbf{V} & \mathbf{V}\mathbf{A}^\top \cr \mathbf{A}\mathbf{V} & \mathbf{A}\mathbf{V}\mathbf{A}^\top + \mathbf{R} \end{pmatrix}\Big)`$ ; $\mathbf{y} \sim \mathcal{N}(\mathbf{A}\mathbf{m} + \mathbf{b},\ \mathbf{A}\mathbf{V}\mathbf{A}^\top + \mathbf{R})$ ; $\mathbf{x} \mid \mathbf{y}$ : moyenne $\mathbf{m} + \mathbf{V}\mathbf{A}^\top(\mathbf{A}\mathbf{V}\mathbf{A}^\top + \mathbf{R})^{-1}(\mathbf{y} - \mathbf{A}\mathbf{m} - \mathbf{b})$, covariance $\mathbf{V} - \mathbf{V}\mathbf{A}^\top(\mathbf{A}\mathbf{V}\mathbf{A}^\top + \mathbf{R})^{-1}\mathbf{A}\mathbf{V} = (\mathbf{V}^{-1} + \mathbf{A}^\top\mathbf{R}^{-1}\mathbf{A})^{-1}$ (Woodbury, admis) |
| régression linéaire bayésienne | $\boldsymbol{\theta} \sim \mathcal{N}(\mathbf{m}_0, \mathbf{S}_0)$, $\mathbf{y} = \boldsymbol{\Phi}\boldsymbol{\theta} + \mathbf{w}$, $\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \sigma^2\mathbf{I})$, $\boldsymbol{\Phi}$ de forme $(n, K)$ : $\mathbf{S}_N = (\mathbf{S}_0^{-1} + \sigma^{-2}\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}$, $\mathbf{m}_N = \mathbf{S}_N(\mathbf{S}_0^{-1}\mathbf{m}_0 + \sigma^{-2}\boldsymbol{\Phi}^\top\mathbf{y})$ (MML Théorème 9.1) ; $n = 0$ : $\mathbf{m}_N = \mathbf{m}_0$, $\mathbf{S}_N = \mathbf{S}_0$ ; $\mathbf{S}_0^{-1} \to \mathbf{0}$ : moindres carrés ; $\mathbf{m}_0 = \mathbf{0}$, $\mathbf{S} _0 = \tau^2\mathbf{I}$ : $\mathbf{m} _N = \big(\boldsymbol{\Phi}^\top\boldsymbol{\Phi} + \frac{\sigma^2}{\tau^2}\mathbf{I}\big)^{-1}\boldsymbol{\Phi}^\top\mathbf{y}$ (ridge, MAP) ; prédictive $y _\star \mid \mathbf{y} \sim \mathcal{N}(\boldsymbol{\phi} _\star^\top\mathbf{m} _N,\ \boldsymbol{\phi} _\star^\top\mathbf{S} _N\boldsymbol{\phi} _\star + \sigma^2)$ ; évidence $p(\mathbf{y}) = \mathcal{N}(\mathbf{y} \mid \boldsymbol{\Phi}\mathbf{m}_0,\ \boldsymbol{\Phi}\mathbf{S}_0\boldsymbol{\Phi}^\top + \sigma^2\mathbf{I})$ (MML (9.64)) |
| maximum de vraisemblance | $\ell(\boldsymbol{\mu}, \boldsymbol{\Sigma}) = -\frac{nd}{2}\ln(2\pi) - \frac n2\ln\det\boldsymbol{\Sigma} - \frac12\sum_i(\mathbf{x}_i - \boldsymbol{\mu})^\top\boldsymbol{\Sigma}^{-1}(\mathbf{x}_i - \boldsymbol{\mu})$ ; $\mathbf{S} = \sum_i(\mathbf{x}_i - \bar{\mathbf{x}})(\mathbf{x}_i - \bar{\mathbf{x}})^\top$ définie positive : $\hat{\boldsymbol{\mu}} = \bar{\mathbf{x}}$, $\hat{\boldsymbol{\Sigma}} = \frac{\mathbf{S}}{n}$ ; $\ell(\hat{\boldsymbol{\mu}}, \hat{\boldsymbol{\Sigma}}) = -\frac n2\big[d\ln(2\pi) + \ln\det\hat{\boldsymbol{\Sigma}} + d\big]$ ; $\mathbb{E}[\hat{\boldsymbol{\Sigma}}] = \frac{n - 1}{n}\boldsymbol{\Sigma}$ ; $\operatorname{rg}\mathbf{S} \le n - 1$ : $\hat{\boldsymbol{\Sigma}}$ singulière si $n \le d$ |
| gradients de ln det et de la trace | $\nabla_{\mathbf{Z}}\ln\det\mathbf{Z} = \mathbf{Z}^{-\top}$ ($\det\mathbf{Z} > 0$), $\nabla_{\mathbf{Z}}\operatorname{tr}(\mathbf{A}\mathbf{Z}) = \mathbf{A}^\top$ (M18) ; astuce de la trace $\mathbf{z}^\top\boldsymbol{\Lambda}\mathbf{z} = \operatorname{tr}(\boldsymbol{\Lambda}\mathbf{z}\mathbf{z}^\top)$ ; $\ln\det\boldsymbol{\Sigma} = -\ln\det\boldsymbol{\Lambda}$ ; au maximum, $\operatorname{tr}(\hat{\boldsymbol{\Sigma}}^{-1}\mathbf{S}) = nd$ |

| entropie différentielle | $h(p) = -\mathbb{E}_p[\ln p(\mathbf{x})]$ ; $\mathrm{KL}(p \thinspace\Vert\thinspace q) = -h(p) - \mathbb{E}_p[\ln q(\mathbf{x})]$ ; $h\big(\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})\big) = \frac12\ln\big((2\pi e)^d\det\boldsymbol{\Sigma}\big) = \frac d2\ln(2\pi e) + \frac12\ln\det\boldsymbol{\Sigma}$, sans $\boldsymbol{\mu}$ ; unités multipliées par $a$ : $h$ augmente de $d\ln a$ ; elle peut être négative |
| lemme de la trace | $\mathbf{x}$ de moyenne $\boldsymbol{\mu}$, de covariance $\boldsymbol{\Sigma}$ (gaussien ou non) : $\mathbb{E}\big[(\mathbf{x} - \mathbf{m})^\top\mathbf{A}(\mathbf{x} - \mathbf{m})\big] = \operatorname{tr}(\mathbf{A}\boldsymbol{\Sigma}) + (\boldsymbol{\mu} - \mathbf{m})^\top\mathbf{A}(\boldsymbol{\mu} - \mathbf{m})$ ; $\mathbb{E}[\Delta^2] = \operatorname{tr}(\mathbf{I}) = d$ |
| KL entre deux gaussiennes | $\boldsymbol{\delta} = \boldsymbol{\mu}_1 - \boldsymbol{\mu}_0$ : $\mathrm{KL}\big(\mathcal{N}(\boldsymbol{\mu}_0, \boldsymbol{\Sigma}_0) \thinspace\Vert\thinspace \mathcal{N}(\boldsymbol{\mu}_1, \boldsymbol{\Sigma}_1)\big) = \frac12\Big[\operatorname{tr}(\boldsymbol{\Sigma}_1^{-1}\boldsymbol{\Sigma}_0) + \boldsymbol{\delta}^\top\boldsymbol{\Sigma}_1^{-1}\boldsymbol{\delta} - d + \ln\frac{\det\boldsymbol{\Sigma}_1}{\det\boldsymbol{\Sigma}_0}\Big]$ ; $d = 1$ : $\frac12\Big[\frac{\sigma_0^2}{\sigma_1^2} + \frac{(\mu_1 - \mu_0)^2}{\sigma_1^2} - 1 + \ln\frac{\sigma_1^2}{\sigma_0^2}\Big]$ ; même covariance : $\frac12\boldsymbol{\delta}^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\delta}$, symétrique ; contrôle : 0 pour deux lois égales |
| formules de soustraction | $e^{i\gamma}e^{-i\psi} = e^{i(\gamma - \psi)}$ : $\sin(\gamma - \psi) = \sin\gamma\cos\psi - \cos\gamma\sin\psi$, $\cos(\gamma - \psi) = \cos\gamma\cos\psi + \sin\gamma\sin\psi$ |
| interpolation sphérique | $\cos\Omega = \frac{\mathbf{u}^\top\mathbf{v}}{\lVert\mathbf{u}\rVert\thinspace\lVert\mathbf{v}\rVert}$, $\Omega \in\thinspace ]0, \pi[$ : $\operatorname{slerp}(\mathbf{u}, \mathbf{v} ; t) = \frac{\sin((1 - t)\Omega)}{\sin\Omega}\thinspace\mathbf{u} + \frac{\sin(t\Omega)}{\sin\Omega}\thinspace\mathbf{v}$, $t \in [0, 1]$ ; $t = 0$ : $\mathbf{u}$, $t = 1$ : $\mathbf{v}$ ; $\lVert\mathbf{u}\rVert = \lVert\mathbf{v}\rVert = R$ : norme $R$ et angle $t\Omega$ avec $\mathbf{u}$ pour tout $t$ ; $\Omega \to 0$ : coefficients $\to 1 - t$ et $t$ ; non défini si $\sin\Omega = 0$ ; ligne droite entre vecteurs unitaires : milieu de norme $\cos\frac{\Omega}{2}$ |
| arc, corde, latitude et longitude | sphère de rayon $R$, angle au centre $\Omega$ : arc $R\Omega$ ($\Omega$ en radians), corde $2R\sin\frac{\Omega}{2}$, milieu de la corde à $R\cos\frac{\Omega}{2}$ du centre ; latitude $\varphi$, longitude $\lambda$ : $R(\cos\varphi\cos\lambda,\ \cos\varphi\sin\lambda,\ \sin\varphi)$ |

### M25b · Variables latentes et ELBO

Vecteurs en colonne ; $n$ données $\mathbf{x}_i$ (les lignes d'un tableau $(n, d)$ dans `mymath`) ; latent $\mathbf{z}$, ou un numéro $z \in \lbrace1, \ldots, K\rbrace$ pour un mélange (MML (11.58) : un vecteur one-hot) ; paramètres $\boldsymbol{\theta}$, ceux de l'itération $t$ : $\boldsymbol{\theta}_t$ (MML : $\boldsymbol{\theta}^{(t)}$) ; $\mathcal{N}(c \mid \mu, \sigma^2)$ la densité de $\mathcal{N}(\mu, \sigma^2)$ en $c$ ; KL, ELBO, entropies et informations en nats. Ces formules ne sont pas du code : écrire les pas E et M, la log-vraisemblance et l'ELBO d'un mélange est le travail des 🔨 M25b.20 à M25b.22.

| Notion | Formules |
|---|---|
| modèle à variable latente, graphe orienté | $p(\mathbf{x}, \mathbf{z}) = p(\mathbf{z})\thinspace p(\mathbf{x} \mid \mathbf{z})$ ; sur un graphe orienté sans cycle, $p(x_1, \ldots, x_m) = \prod_{j=1}^m p(x_j \mid \mathrm{pa}_j)$ (MML (8.31)) ; tirage ancestral : chaque parent avant ses enfants, chacun selon sa loi sachant ses parents déjà tirés |

### M26 · Chaînes de Markov et équation de Bellman

Pas de MML pour ce chapitre (le livre ne traite pas les chaînes de Markov). ### M27 · Jeux et distances entre lois

MML §7.2 (relu : l'inégalité minimax (7.23), la dualité faible (7.27)) et §7.3.1 en option ; MML n'a ni stratégie mixte, ni équilibre de Nash, ni distance de Wasserstein. $\mathbf{G} = (g_{ij})$, de forme $(m, n)$, est la matrice des gains : $g_{ij}$ est ce que gagne le joueur des lignes (qui maximise) et ce que paie le joueur des colonnes (qui minimise) ; dans un jeu $2 \times 2$, $p$ et $q$ sont les probabilités de la première ligne et de la première colonne ; MML (7.23) appelle $\mathbf{x}$ le joueur qui **minimise**. $\ln$ partout : JS, KL et PSI sont en nats (1 bit $= \ln 2$ nat). $W_p$ est la distance, $W_p^p$ le coût minimal ; $F$ et $G$ (en italique) sont des fonctions de répartition, $F^{-1}(u) = \inf\lbrace x : F(x) \ge u\rbrace$ (M02a).

### M28 · Matrice de Gram, montée sur l'entrée et lois tronquées

Pas de MML pour ce chapitre (le livre ne traite ni la variation totale, ni les fréquences, ni les troncatures, ni les itérations sur un ensemble fini ; $\mathbf{A}^\top\mathbf{A}$, $\mathbf{A}\mathbf{A}^\top$ et la matrice de Gram d'un noyau ont été lus en M12d et M13b). Les points $\mathbf{x} _1, \ldots, \mathbf{x} _n$ sont les **lignes** de $\mathbf{X}$, de forme $(n, d)$ ; $\mathbf{D}^{(2)}$ est la matrice des **carrés** des distances, $\mathbf{J} = \mathbf{I} - \frac1n\mathbf{1}\mathbf{1}^\top$ la matrice de centrage (notée $\mathbf{C}$ en M20). $\mathbf{g} = \nabla f(\mathbf{x})$ a la forme de $\mathbf{x}$. Une grille $x _{ij}$ a ses lignes et ses colonnes numérotées à partir de 0 ; $\mathrm{VT}$ est la somme des **carrés** des différences entre voisines (la version avec des valeurs absolues est toujours nommée) ; $f$ est une fréquence en cycles par case, $\omega = 2\pi f$ la même en radians par case. Une loi est un vecteur de probabilités $\mathbf{p} = (p_0, \ldots, p _{K-1})$, jamais des scores ; entre deux probabilités égales, la plus petite issue passe d'abord ; $m$ est le seuil d'un top-p ; $\ln$ partout (nats). Au §6, $\mu$ et $\lambda$ sont la prépériode et la période d'une suite.
