## Partie III · ML classique

### M12a · Espaces vectoriels et applications linéaires

| Notion | Formules |
|---|---|
| sous-espace | $\mathbf{0} \in U$ et $\lambda\mathbf{x} + \mu\mathbf{y} \in U$ ; les solutions de $\mathbf{A}\mathbf{x} = \mathbf{0}$ en forment un ; l'intersection de deux sous-espaces aussi, leur réunion presque jamais |
| combinaison, indépendance | $\mathbf{b} \in \operatorname{Vect}(\mathbf{v}_1, \ldots, \mathbf{v}_k) \iff [\mathbf{v}_1 \cdots \mathbf{v}_k]\thinspace\boldsymbol{\lambda} = \mathbf{b}$ a une solution ; libre $\iff$ chaque colonne porte un pivot $\iff \operatorname{rg} = k$ ; plus de $n$ vecteurs de $\mathbb{R}^n$ : liés |
| base, dimension | base = libre + génératrice ; $\dim\mathbb{R}^n = n$, $\dim\mathbb{R}_d[x] = d + 1$, $\dim\mathbb{R}^{m \times n} = mn$ ; $n$ vecteurs libres d'un espace de dimension $n$ forment une base |
| coordonnées | $\mathbf{v} = \mathbf{B}\mathbf{c}$ (base en colonnes) ; $\mathbf{c} = \mathbf{B}^{-1}\mathbf{v}$ ; base d'un sous-espace : $\mathbf{B}^\top\mathbf{B}\thinspace\mathbf{c} = \mathbf{B}^\top\mathbf{v}$, puis vérifier $\mathbf{B}\mathbf{c} = \mathbf{v}$ |
| rang | $\operatorname{rg}(\mathbf{A}) = \dim\operatorname{Im}\mathbf{A} = \operatorname{rg}(\mathbf{A}^\top) \le \min(m, n)$ ; $\operatorname{rg}(\mathbf{A}\mathbf{B}) \le \min(\operatorname{rg}\mathbf{A}, \operatorname{rg}\mathbf{B})$ ; $\operatorname{rg}(\mathbf{A}^\top\mathbf{A}) = \operatorname{rg}(\mathbf{A})$ ; $\operatorname{rg}(\mathbf{u}\mathbf{v}^\top) = 1$ ; tableau centré de $n$ lignes : $\operatorname{rg} \le n - 1$ |
| application linéaire | $f(\lambda\mathbf{x} + \mu\mathbf{y}) = \lambda f(\mathbf{x}) + \mu f(\mathbf{y})$ ; colonne $j$ de la matrice $= f(\mathbf{e}_j)$ (coordonnées de $f(\mathbf{b}_j)$ dans d'autres bases) ; « $f$ puis $g$ » $= \mathbf{B}\mathbf{A}$ |
| noyau, image | $\ker\mathbf{A} \subseteq \mathbb{R}^n$, $\operatorname{Im}\mathbf{A} \subseteq \mathbb{R}^m$ ; base du noyau : $x_j = 1$ (colonne libre $j$), $x_p = -R_{ij}$ ; base de l'image : les colonnes de $\mathbf{A}$ aux indices des pivots ; $\dim\ker\mathbf{A} + \operatorname{rg}(\mathbf{A}) = n$ ; injective $\iff \ker = \lbrace\mathbf{0}\rbrace$ |
| solutions | $\mathbf{A}\mathbf{x} = \mathbf{b}$ : solvable $\iff \mathbf{b} \in \operatorname{Im}\mathbf{A}$ ; solutions $= \mathbf{x}_p + \ker\mathbf{A}$, $n - \operatorname{rg}(\mathbf{A})$ paramètres ; $\ker(\mathbf{X}^\top\mathbf{X}) = \ker\mathbf{X}$ |
| changement de base | $\mathbf{x} = \mathbf{S}\mathbf{x}'$ ; $\mathbf{A}' = \mathbf{S}^{-1}\mathbf{A}\mathbf{S}$ (semblables) ; entre deux espaces $\mathbf{T}^{-1}\mathbf{A}\mathbf{S}$ (équivalentes) ; colonne $j$ de $\mathbf{A}'$ = coordonnées de $\mathbf{A}\mathbf{s}_j$ |
| affine | $\varphi(\mathbf{x}) = \mathbf{A}\mathbf{x} + \mathbf{b}$, $\mathbf{b} = \varphi(\mathbf{0})$ ; conserve les combinaisons de coefficients de somme 1 ; bijective $\iff \mathbf{A}$ inversible ; $\varphi^{-1}(\mathbf{y}) = \mathbf{A}^{-1}(\mathbf{y} - \mathbf{b})$, de translation $-\mathbf{A}^{-1}\mathbf{b}$ ; sous-espace affine $\mathbf{x}_0 + U$ |

### M12b · Orthogonalité et projections

| Notion | Formules |
|---|---|
| produit scalaire | bilinéaire, symétrique, défini positif ; sur $\mathbb{R}^n$, $\langle \mathbf{x}, \mathbf{y} \rangle_{\mathbf{M}} = \mathbf{x}^\top\mathbf{M}\mathbf{y}$, $\mathbf{M}$ symétrique définie positive ($a > 0$ et $ac - b^2 > 0$ en dimension 2) ; $\lVert \mathbf{x} \rVert = \sqrt{\langle \mathbf{x}, \mathbf{x} \rangle}$, $\cos\theta = \frac{\langle \mathbf{x}, \mathbf{y} \rangle}{\lVert \mathbf{x} \rVert\thinspace\lVert \mathbf{y} \rVert}$ ; Cauchy-Schwarz $\lvert \langle \mathbf{x}, \mathbf{y} \rangle \rvert \le \lVert \mathbf{x} \rVert\thinspace\lVert \mathbf{y} \rVert$ |
| base orthonormée | $\langle \mathbf{q}_i, \mathbf{q} _j \rangle = \delta _{ij}$ ; $c_i = \langle \mathbf{v}, \mathbf{q}_i \rangle$ (orthogonale : $c_i = \frac{\langle \mathbf{v}, \mathbf{u}_i \rangle}{\lVert \mathbf{u}_i \rVert^2}$) ; Parseval $\lVert \mathbf{v} \rVert^2 = \sum c_i^2$ |
| matrice orthogonale | $\mathbf{Q}^\top\mathbf{Q} = \mathbf{Q}\mathbf{Q}^\top = \mathbf{I}$, $\mathbf{Q}^{-1} = \mathbf{Q}^\top$ ; $(\mathbf{Q}\mathbf{x}) \cdot (\mathbf{Q}\mathbf{y}) = \mathbf{x} \cdot \mathbf{y}$ ; colonnes orthonormées sans être carrée : $\mathbf{Q}^\top\mathbf{Q} = \mathbf{I}_k$ seulement |
| Gram-Schmidt | $\mathbf{v}_k = \mathbf{a} _k - \sum _{j\lt k} \langle \mathbf{a}_k, \mathbf{q}_j \rangle\thinspace\mathbf{q}_j$, $\mathbf{q}_k = \frac{\mathbf{v}_k}{\lVert \mathbf{v}_k \rVert}$ ; modifié : $\mathbf{v} \leftarrow \mathbf{v} - \langle \mathbf{v}, \mathbf{q}_j \rangle\thinspace\mathbf{q}_j$ ; coût $\approx 2mn^2$ |
| complément orthogonal | $U^\perp = \lbrace\mathbf{x} : \langle \mathbf{x}, \mathbf{u} \rangle = 0\ \forall \mathbf{u} \in U\rbrace$ ; $\dim U + \dim U^\perp = n$ ; $(\operatorname{Im}\mathbf{A})^\perp = \ker\mathbf{A}^\top$, $\ker\mathbf{A} = (\operatorname{Im}\mathbf{A}^\top)^\perp$ |
| projection | $\mathbf{p} \in U$ et $\mathbf{v} - \mathbf{p} \perp U$ ; $\mathbf{p} = \mathbf{Q}\mathbf{Q}^\top\mathbf{v}$, ou $\mathbf{A}^\top\mathbf{A}\thinspace\mathbf{c} = \mathbf{A}^\top\mathbf{v}$ et $\mathbf{p} = \mathbf{A}\mathbf{c}$ ; $\lVert \mathbf{v} - \mathbf{u} \rVert^2 = \lVert \mathbf{v} - \mathbf{p} \rVert^2 + \lVert \mathbf{p} - \mathbf{u} \rVert^2$ ; $\mathbf{P}^2 = \mathbf{P} = \mathbf{P}^\top$, $\operatorname{tr}\mathbf{P} = \dim U$ ; centrer : $\mathbf{I} - \frac{1}{n}\mathbf{1}\mathbf{1}^\top$ |
| moindres carrés | $\hat{\mathbf{y}} = \pi_{\operatorname{Im}\mathbf{X}}(\mathbf{y})$ ; $\mathbf{X}^\top(\mathbf{y} - \mathbf{X}\mathbf{w}^\ast) = \mathbf{0}$ ; $\lVert \mathbf{y} \rVert^2 = \lVert \hat{\mathbf{y}} \rVert^2 + \lVert \mathbf{r} \rVert^2$ ; avec une colonne de 1, $\sum r_i = 0$ |
| QR | $\mathbf{A} = \mathbf{Q}\mathbf{R}$, $r_{jk} = \langle \mathbf{q} _j, \mathbf{a} _k \rangle$ ($j \le k$), $r _{kk} = \lVert \mathbf{v} _k \rVert > 0$ ; $\mathbf{R}\mathbf{w}^\ast = \mathbf{Q}^\top\mathbf{y}$ par remontée : $w_i = \big(z_i - \sum _{j>i} r  _{ij}w_j\big)/r _{ii}$ |
| fonctions | $\langle f, g \rangle = \int_a^b f\thinspace g$ ; sur $[-1 ; 1]$, Gram-Schmidt sur $1, x, x^2$ donne $1, x, x^2 - \frac{1}{3}$ |

### M12c · Valeurs propres et matrices symétriques

| Notion | Formules |
|---|---|
| déterminant | $2 \times 2$ : $ad - bc$ ; cofacteurs : $\det\mathbf{A} = \sum_j (-1)^{i+j}a_{ij}\det\mathbf{A}_{ij}$ ; échanger deux lignes : $\times(-1)$, multiplier une ligne par $c$ : $\times c$, ajouter un multiple d'une ligne : inchangé ; triangulaire : produit de la diagonale ; $\det(\mathbf{A}\mathbf{B}) = \det\mathbf{A}\det\mathbf{B}$, $\det\mathbf{A}^\top = \det\mathbf{A}$, $\det(\mathbf{A}^{-1}) = 1/\det\mathbf{A}$, $\det(c\mathbf{A}) = c^n\det\mathbf{A}$ ; $\det\mathbf{A} \ne 0 \iff \mathbf{A}$ inversible |
| trace | $\operatorname{tr}\mathbf{A} = \sum a_{ii}$ ; $\operatorname{tr}(\mathbf{A}\mathbf{B}) = \operatorname{tr}(\mathbf{B}\mathbf{A})$ ; $\operatorname{tr}(\mathbf{S}^{-1}\mathbf{A}\mathbf{S}) = \operatorname{tr}\mathbf{A}$ ; $\operatorname{tr}(\mathbf{x}\mathbf{y}^\top) = \mathbf{y}^\top\mathbf{x}$ ; $\operatorname{tr}(\mathbf{X}^\top\mathbf{X}) = \sum x_{ij}^2$ |
| valeurs propres | $\mathbf{A}\mathbf{v} = \lambda\mathbf{v}$, $\mathbf{v} \ne \mathbf{0}$ ; $\det(\mathbf{A} - \lambda\mathbf{I}) = 0$ ; en dimension 2, $\lambda^2 - (\operatorname{tr}\mathbf{A})\lambda + \det\mathbf{A} = 0$ ; $\sum\lambda_i = \operatorname{tr}\mathbf{A}$, $\prod\lambda_i = \det\mathbf{A}$ ; $\mathbf{A}^k$, $\mathbf{A}^{-1}$, $\mathbf{A} + c\mathbf{I}$ : $\lambda^k$, $1/\lambda$, $\lambda + c$ |
| nombres complexes (minimum) | $i^2 = -1$, $\overline{a + ib} = a - ib$, $z\bar z = \lvert z\rvert^2 = a^2 + b^2$ ; si $\Delta = t^2 - 4d < 0$, $\lambda^2 - t\lambda + d$ a les racines conjuguées $\frac t2 \pm i\frac{\sqrt{-\Delta}}{2}$ ; $\bar{\mathbf{z}}^\top\mathbf{z} = \sum\lvert z_i\rvert^2 > 0$ pour $\mathbf{z} \ne \mathbf{0}$ ; une matrice réelle $n \times n$ a $n$ valeurs propres complexes, comptées avec leur multiplicité ; les non réelles vont par paires conjuguées |
| diagonalisation | $\mathbf{A} = \mathbf{P}\mathbf{D}\mathbf{P}^{-1}$ si les vecteurs propres forment une base ; $\mathbf{A}^k = \mathbf{P}\mathbf{D}^k\mathbf{P}^{-1}$, $f(\mathbf{A}) = \mathbf{P}f(\mathbf{D})\mathbf{P}^{-1}$ ; $1 \le$ multiplicité géométrique $\le$ algébrique |
| méthode de la puissance | $\mathbf{x}_{k+1} = \mathbf{A}\mathbf{x}_k/\lVert \mathbf{A}\mathbf{x} _k \rVert$ ; écart $\propto \lvert\lambda_2/\lambda_1\rvert^k$ ; $k \approx d/(-\log _{10}\lvert\lambda_2/\lambda_1\rvert)$ pas pour $d$ chiffres ; déflation $\mathbf{A} - \lambda_1\mathbf{q}_1\mathbf{q}_1^\top$ |
| théorème spectral | $\mathbf{A} = \mathbf{A}^\top \Rightarrow \mathbf{A} = \mathbf{Q}\boldsymbol{\Lambda}\mathbf{Q}^\top = \sum_i \lambda_i\mathbf{q} _i\mathbf{q} _i^\top$, $\lambda_i$ réelles, $\mathbf{Q}^\top\mathbf{Q} = \mathbf{I}$ ; $R(\mathbf{x}) = \frac{\mathbf{x}^\top\mathbf{A}\mathbf{x}}{\mathbf{x}^\top\mathbf{x}} = \frac{\sum\lambda_iy_i^2}{\sum y_i^2} \in [\lambda _{\min} ; \lambda _{\max}]$, $\mathbf{y} = \mathbf{Q}^\top\mathbf{x}$ |
| définie positive | $\mathbf{x}^\top\mathbf{A}\mathbf{x} > 0$ ($\mathbf{x} \ne \mathbf{0}$) $\iff$ tous les $\lambda_i > 0$ $\iff$ mineurs principaux $> 0$ $\iff$ Cholesky existe ; $\mathbf{X}^\top\mathbf{X} \succeq 0$, $\succ 0$ si les colonnes sont libres ; $\frac{1}{2}\mathbf{x}^\top\mathbf{A}\mathbf{x} - \mathbf{b}^\top\mathbf{x}$ minimale en $\mathbf{A}^{-1}\mathbf{b}$ ; lignes de niveau $\mathbf{x}^\top\mathbf{A}\mathbf{x} = c$ : demi-axes $\sqrt{c/\lambda_i}$ le long des $\mathbf{q}_i$ |
| hessienne et convexité | $(\nabla^2 f)_{ij} = \frac{\partial^2 f}{\partial x_i\partial x_j}$, symétrique (dérivées secondes continues) ; $f$ convexe $\iff \nabla^2 f(\mathbf{x}) \succeq 0$ en tout $\mathbf{x}$ ; $\succ 0$ partout : strictement convexe |
| Cholesky | $\mathbf{A} = \mathbf{L}\mathbf{L}^\top$ ; $l_{jj} = \sqrt{a_{jj} - \sum_{k\lt j} l_{jk}^2}$, $l_{ij} = \big(a_{ij} - \sum_{k\lt j} l_{ik}l_{jk}\big)/l_{jj}$ ($i > j$) ; $\mathbf{A}\mathbf{x} = \mathbf{b}$ : $\mathbf{L}\mathbf{z} = \mathbf{b}$ puis $\mathbf{L}^\top\mathbf{x} = \mathbf{z}$ ; $\det\mathbf{A} = \prod l_{ii}^2$ |
| covariance et blanchiment | $\operatorname{Cov}(\mathbf{A}\mathbf{x} + \mathbf{b}) = \mathbf{A}\boldsymbol{\Sigma}\mathbf{A}^\top$, $\mathbb{V}(\mathbf{w}^\top\mathbf{x}) = \mathbf{w}^\top\boldsymbol{\Sigma}\mathbf{w}$ ; $\boldsymbol{\Sigma}^{\pm 1/2} = \mathbf{Q}\boldsymbol{\Lambda}^{\pm 1/2}\mathbf{Q}^\top$ ; $\mathbf{W}\boldsymbol{\Sigma}\mathbf{W}^\top = \mathbf{I}$ pour $\mathbf{W} = \boldsymbol{\Sigma}^{-1/2}$ (ZCA), $\boldsymbol{\Lambda}^{-1/2}\mathbf{Q}^\top$ (ACP), $\mathbf{L}^{-1}$ (Cholesky) ; Mahalanobis $\sqrt{\mathbf{d}^\top\boldsymbol{\Sigma}^{-1}\mathbf{d}} = \lVert \mathbf{W}\mathbf{d} \rVert$ |

### M12d · SVD et analyse en composantes principales

| Notion | Formules |
|---|---|
| SVD | $\mathbf{A} = \mathbf{U}\mathbf{S}\mathbf{V}^\top = \sum_{i \le r} s_i\mathbf{u}_i\mathbf{v}_i^\top$ ; $s_i = \sqrt{\lambda_i(\mathbf{A}^\top\mathbf{A})}$, $\mathbf{A}^\top\mathbf{A}\mathbf{v}_i = s_i^2\mathbf{v}_i$, $\mathbf{u}_i = \mathbf{A}\mathbf{v}_i/s_i$ ; $\mathbf{A}\mathbf{A}^\top$ a les mêmes valeurs propres non nulles ; $\lvert\det\mathbf{A}\rvert = \prod s_i$ (carrée) ; symétrique : $s_i = \lvert\lambda_i\rvert$ |
| géométrie | le cercle unité devient une ellipse de demi-axes $s_i\mathbf{u}_i$ ; $s_n\lVert \mathbf{x} \rVert \le \lVert \mathbf{A}\mathbf{x} \rVert \le s_1\lVert \mathbf{x} \rVert$ ($n \le m$) ; $\lVert \mathbf{A} \rVert_2 = s_1$, $\lVert \mathbf{A}\mathbf{B} \rVert_2 \le \lVert \mathbf{A} \rVert_2\lVert \mathbf{B} \rVert_2$ |
| rang faible | $\lVert \mathbf{A} \rVert_F^2 = \sum a_{ij}^2 = \sum s_i^2$ ; $\mathbf{A} _k = \sum _{i \le k} s_i\mathbf{u}_i\mathbf{v}_i^\top$, $\lVert \mathbf{A} - \mathbf{A} _k \rVert_F^2 = \sum _{i > k} s_i^2$, $\lVert \mathbf{A} - \mathbf{A} _k \rVert_2 = s _{k+1}$ ; stockage $k(m + n + 1)$, rentable si $k < \frac{mn}{m + n + 1}$ |
| pseudo-inverse | $\mathbf{A}^+ = \mathbf{V}_r\mathbf{S}_r^{-1}\mathbf{U}_r^\top$ ; $\mathbf{x}^+ = \mathbf{A}^+\mathbf{b}$ (moindres carrés de norme minimale) ; inversible : $\mathbf{A}^{-1}$ ; colonnes libres : $(\mathbf{A}^\top\mathbf{A})^{-1}\mathbf{A}^\top$ ; rang 1 : $\mathbf{A}^\top/\lVert \mathbf{A} \rVert_F^2$ ; $\mathbf{A}\mathbf{A}^+ = \mathbf{U}_r\mathbf{U}_r^\top$ ; ridge : $1/s_i \to \frac{s_i}{s_i^2 + \alpha}$ |
| conditionnement | $\kappa = s_{\max}/s_{\min}$ ; $\frac{\lVert \delta\mathbf{x} \rVert}{\lVert \mathbf{x} \rVert} \le \kappa\frac{\lVert \delta\mathbf{b} \rVert}{\lVert \mathbf{b} \rVert}$ ; $\kappa(\mathbf{A}^\top\mathbf{A}) = \kappa^2$ ; $2 \times 2$ : $s_1^2 + s_2^2 = \lVert \mathbf{A} \rVert_F^2$, $s_1s_2 = \lvert\det\mathbf{A}\rvert$ |
| axes principaux | $\mathbf{C} = \frac{1}{n-1}\mathbf{X}_c^\top\mathbf{X}_c$ ; variance le long de $\mathbf{u}$ unitaire : $\mathbf{u}^\top\mathbf{C}\mathbf{u}$, maximale ($\lambda_1$) en $\mathbf{u}_1$ ; $\mathbf{C}\mathbf{u}_j = \lambda_j\mathbf{u}_j$ ; $\sum\lambda_j = \operatorname{tr}\mathbf{C}$ ; changement d'unités : $\mathbf{D}\mathbf{C}\mathbf{D}$, corrélation inchangée |
| ACP | scores $\mathbf{Z} = \mathbf{X}_c\mathbf{W} _k$, $t _{ij} = \mathbf{u}_j^\top(\mathbf{x}_i - \boldsymbol{\mu})$ ; $\hat{\mathbf{X}} = \mathbf{Z}\mathbf{W}_k^\top + \boldsymbol{\mu}$ ; $\operatorname{Cov}(\mathbf{Z}) = \operatorname{diag}(\lambda_1, \ldots, \lambda_k)$ ; par la SVD $\mathbf{X}_c = \mathbf{U}\mathbf{S}\mathbf{V}^\top$ : axes $\mathbf{v}_j$, $\lambda_j = s_j^2/(n - 1)$, scores $\mathbf{U}\mathbf{S}$ |
| variance expliquée, erreur | part $\lambda_j/\sum_l\lambda_l$ ; erreur moyenne $\frac{1}{n}\sum_i\lVert \mathbf{x} _i - \hat{\mathbf{x}} _i \rVert^2 = \frac{n-1}{n}\sum _{j > k}\lambda_j$ ; d'un exemple : $\sum  _{j > k} t _{ij}^2$ ; $n < p$ : au plus $n - 1$ variances non nulles, axes $\mathbf{X}_c^\top\mathbf{w}/\lVert \mathbf{X}_c^\top\mathbf{w} \rVert$ pour $\mathbf{X}_c\mathbf{X}_c^\top\mathbf{w} = \mu\mathbf{w}$ |
| t-SNE | $p_{j \mid i} = \frac{\exp(-\lVert \mathbf{x} _i - \mathbf{x} _j \rVert^2/2\sigma_i^2)}{\sum _{l \ne i}\exp(-\lVert \mathbf{x} _i - \mathbf{x} _l \rVert^2/2\sigma_i^2)}$ ; perplexité $2^{H(P_i)}$, $H$ en bits ; $p _{ij} = \frac{p _{j \mid i} + p  _{i \mid j}}{2n}$ ; carte : $q _{ij} \propto (1 + \lVert \mathbf{y}_i - \mathbf{y}_j \rVert^2)^{-1}$, minimiser $\mathrm{KL}(P \Vert Q)$ |

### M13a · Vraisemblance et régression logistique

| Notion | Formules |
|---|---|
| vraisemblance | i.i.d. : $L(\boldsymbol{\theta}) = \prod_i p(x_i \mid \boldsymbol{\theta})$, $\ell = \sum_i \ln p(x_i \mid \boldsymbol{\theta})$ ; Bernoulli : $\ell(p) = k\ln p + (n - k)\ln(1 - p)$, $\hat{p} = \frac{k}{n}$ ; catégorielle : $\ell = \sum_k n_k\ln p_k$, $\hat{p}_k = \frac{n_k}{N}$, lissée $\frac{n_k + \alpha}{N + K\alpha}$ |
| loi normale | $\ell(\mu, v) = -\frac{n}{2}\ln(2\pi v) - \frac{1}{2v}\sum_i(x_i - \mu)^2$ ; $\hat{\mu} = \bar{x}$, $\hat{\sigma}^2 = \frac{1}{n}\sum_i(x_i - \hat{\mu})^2$, $\mathbb{E}[\hat{\sigma}^2] = \frac{n-1}{n}\sigma^2$ ; $\ell(\hat{\mu}, \hat{\sigma}^2) = -\frac{n}{2}\big(\ln(2\pi\hat{\sigma}^2) + 1\big)$ |
| log-loss | $-\frac{1}{n}\sum_i[y_i\ln\hat{p}_i + (1 - y_i)\ln(1 - \hat{p}_i)] = -\frac{1}{n}\ell$ ; multiclasse : $-\frac{1}{n}\sum_i\ln\hat{q}_i(y_i)$ ; moyenne pour un label de probabilité $\pi$ : $H(\pi) + \mathrm{KL}(\pi \Vert q)$ ; meilleur modèle constant : $H(\hat{p})$ (nats) ; bits : $\div\ln 2$ |
| sigmoïde, softplus | $\sigma(z) = \frac{1}{1 + e^{-z}}$, $\sigma(-z) = 1 - \sigma(z)$, $\frac{\sigma}{1 - \sigma} = e^z$ ; $s(z) = \ln(1 + e^z) = \max(z, 0) + \ln(1 + e^{-\lvert z \rvert})$, $s(z) - s(-z) = z$ ; $-\ln\sigma(z) = s(-z)$, $-\ln(1 - \sigma(z)) = s(z)$ ; terme de log-loss : $s(z) - yz$ |
| convexité | $\mathrm{LSE}(\mathbf{u}) = \ln\sum_k e^{u_k}$, $\max_k u_k \le \mathrm{LSE} \le \max_k u_k + \ln K$ ; sur une droite, $g'' = \sum_k\pi_kd_k^2 - (\sum_k\pi_kd_k)^2 \ge 0$ ; $s(z) = \mathrm{LSE}(0, z)$ ; convexe ∘ affine est convexe |
| régression logistique | $P(Y = 1 \mid \mathbf{x}) = \sigma(\mathbf{w} \cdot \mathbf{x} + b)$ ; log-cote $= \mathbf{w} \cdot \mathbf{x} + b$ ; cote $\times e^{w_j}$ quand $x_j + 1$ ; niveau $c$ : $\mathbf{w} \cdot \mathbf{x} + b = \operatorname{logit}(c)$ ; $J(\mathbf{w}, b) = \frac{1}{n}\sum_i[s(z_i) - y_iz_i]$, convexe |
| Naïve Bayes | $P(Y = k \mid \mathbf{x}) \propto \pi_k\prod_j p(x_j \mid k)$ ; $m^p - 1$ contre $p(m - 1)$ probabilités par classe ; deux gaussiennes de même variance : $w = \frac{\mu_1 - \mu_0}{\sigma^2}$, $b = \frac{\mu_0^2 - \mu_1^2}{2\sigma^2} + \ln\frac{\pi_1}{\pi_0}$ |
| impuretés | $H(\mathbf{p}) = -\sum_k p_k\log_2 p_k \le \log_2 K$ ; $G(\mathbf{p}) = 1 - \sum_k p_k^2 \le 1 - \frac{1}{K}$ ; gain d'information : $H(Y) - H(Y \mid X) = I(X ; Y)$ |
| réduction de variance | $V = \frac{n_A}{n}V_A + \frac{n_B}{n}V_B + \frac{n_A}{n}(m_A - m)^2 + \frac{n_B}{n}(m_B - m)^2$ (intra + inter, en $\frac{1}{n}$) |

### M13b · Optimisation sous contraintes et SVM

| Notion | Formules |
|---|---|
| Lagrange | $\min f$ sous $g = 0$ : $\nabla f + \lambda\nabla g = \mathbf{0}$, $g = 0$ (si $\nabla g \ne \mathbf{0}$) ; lagrangien $f + \lambda(g - c)$ : $\frac{df^\ast}{dc} = -\lambda$ |
| quadratique sous égalités | $\min \frac12\mathbf{x}^\top\mathbf{Q}\mathbf{x} + \mathbf{c}^\top\mathbf{x}$ sous $\mathbf{A}\mathbf{x} = \mathbf{b}$ : $`\begin{pmatrix} \mathbf{Q} & \mathbf{A}^\top \cr \mathbf{A} & \mathbf{0} \end{pmatrix}\begin{pmatrix} \mathbf{x} \cr \boldsymbol{\lambda} \end{pmatrix} = \begin{pmatrix} -\mathbf{c} \cr \mathbf{b} \end{pmatrix}`$ ; ACP : $\max \mathbf{u}^\top\mathbf{C}\mathbf{u}$ sous $\lVert\mathbf{u}\rVert = 1$ donne $\mathbf{C}\mathbf{u} = \lambda\mathbf{u}$ |
| KKT | $\mathcal{L} = f + \sum_i \mu_i g_i + \sum_j \lambda_j h_j$ ; $g_i \le 0$, $h_j = 0$ ; $\nabla_{\mathbf{x}}\mathcal{L} = \mathbf{0}$ ; $\mu_i \ge 0$ ; $\mu_i g_i = 0$ |
| dualité | $D(\boldsymbol{\mu}, \boldsymbol{\lambda}) = \inf_{\mathbf{x}} \mathcal{L}$, concave ; $D \le f(\mathbf{x})$ pour $\mathbf{x}$ admissible ; convexe + Slater : $\max D = \min f$ ; QP sous $\mathbf{A}\mathbf{x} \le \mathbf{b}$ : $D(\boldsymbol{\mu}) = -\frac12(\mathbf{c} + \mathbf{A}^\top\boldsymbol{\mu})^\top\mathbf{Q}^{-1}(\mathbf{c} + \mathbf{A}^\top\boldsymbol{\mu}) - \boldsymbol{\mu}^\top\mathbf{b}$ |
| SVM à marge dure | $\min \frac12\lVert\mathbf{w}\rVert^2$ sous $y_i(\mathbf{w} \cdot \mathbf{x}_i + b) \ge 1$ ; $\rho = \frac{1}{\lVert\mathbf{w}\rVert}$, bande $\frac{2}{\lVert\mathbf{w}\rVert}$ ; $\mathbf{w} = \sum_i \alpha_i y_i\mathbf{x}_i$, $\sum_i \alpha_i y_i = 0$, $\alpha_i(t_i - 1) = 0$ |
| marge souple | $J = \frac12\lVert\mathbf{w}\rVert^2 + C\sum_i \max(0, 1 - t_i)$, $t_i = y_i(\mathbf{w} \cdot \mathbf{x} _i + b)$ ; $\frac{J}{nC} = \frac1n\sum_i \max(0, 1 - t_i) + \frac{\lambda}{2}\lVert\mathbf{w}\rVert^2$, $\lambda = \frac{1}{nC}$ ; sous-gradient : $\mathbf{g}  _{\mathbf{w}} = \mathbf{w} - C\sum _{t_i < 1} y_i\mathbf{x} _i$, $g_b = -C\sum _{t_i < 1} y_i$ |
| dual de la SVM | $\max \sum_i \alpha_i - \frac12\sum_{i,j}\alpha_i\alpha_jy_iy_j\thinspace k(\mathbf{x}_i, \mathbf{x}_j)$ sous $0 \le \alpha_i \le C$, $\sum_i \alpha_iy_i = 0$ ; $\alpha_i = 0 \Rightarrow t_i \ge 1$, $0 < \alpha_i < C \Rightarrow t_i = 1$, $\alpha_i = C \Rightarrow t_i \le 1$ ; $s(\mathbf{x}) = \sum_i \alpha_iy_i\thinspace k(\mathbf{x}_i, \mathbf{x}) + b$ |

### M22 · Récurrences vectorielles, rayon spectral et normes de matrices

Convention colonne : $\mathbf{x}_{t+1} = \mathbf{A}\mathbf{x}_t + \mathbf{B}\mathbf{u}_t$, $\mathbf{A}$ de forme $(n, n)$, $\mathbf{B}$ de forme $(n, m)$, $y_t = \mathbf{C}\mathbf{x}_t$ avec $\mathbf{C}$ de forme $(1, n)$ ; $t$ compte les pas ; $\lVert\cdot\rVert$ est une norme induite, la même pour les vecteurs et pour les matrices.
