# Glossaire français ↔ anglais · A à C

*Une partie de [Glossaire français ↔ anglais](glossaire.md) : l'index donne les autres.*

| Français | Anglais | Définition courte | Chapitre |
|---|---|---|---|
| a priori conjugué | conjugate prior | un a priori dont l'a posteriori est de la même famille ; la loi Beta pour la binomiale : $\mathrm{Beta}(a, b) \to \mathrm{Beta}(a + k,\ b + n - k)$ | M04 |
| a priori, a posteriori | prior, posterior | la loi d'un paramètre ou d'une hypothèse avant de voir les données ; après, sachant les données ; avec un a priori et une vraisemblance gaussiens, l'a posteriori est gaussien : les précisions s'additionnent, et la moyenne est pondérée par les précisions (M25a) ; M25b dit *prior* et *posterior* : le posterior d'un latent est $p(\mathbf{z} \mid \mathbf{x}) = \frac{p(\mathbf{z})\thinspace p(\mathbf{x} \mid \mathbf{z})}{p(\mathbf{x})}$ | M04, M25a, M25b |
| absorption | absorption (swamping) | un petit nombre ajouté à un grand disparaît à l'arrondi : $10^{16} + 1$ donne $10^{16}$ en `float64` | M05a |
| accuracy | accuracy | $P(\hat{Y} = Y)$ : la proportion de prédictions justes ; trompeuse quand une classe est rare | M03 |
| ACP (analyse en composantes principales) | principal component analysis (PCA) | centrer les données, les projeter sur les $k$ premiers axes principaux (les scores $\mathbf{Z} = \mathbf{X}_c\mathbf{W}_k$), et reconstruire $\hat{\mathbf{X}} = \mathbf{Z}\mathbf{W}_k^\top + \boldsymbol{\mu}$ : le sous-espace de dimension $k$ qui garde le plus de variance, et rend l'erreur de reconstruction la plus petite ; en pratique, par la SVD des données centrées, ou en diagonalisant la covariance quand $n \gg p$ ; l'ACP probabiliste (M25b) en fait un modèle à variables latentes, dont le maximum de vraisemblance engendre le même sous-espace | M12d, M25b |
| ACP probabiliste | probabilistic PCA (PPCA) | le modèle $\mathbf{z} \sim \mathcal{N}(\mathbf{0}, \mathbf{I}_k)$, $\mathbf{x} = \mathbf{W}\mathbf{z} + \boldsymbol{\mu} + \boldsymbol{\varepsilon}$, $\boldsymbol{\varepsilon} \sim \mathcal{N}(\mathbf{0}, \sigma^2\mathbf{I}_d)$, avec $\mathbf{W}$ de forme $(d, k)$ (ses colonnes sont les poids des facteurs, *factor loadings*) : un modèle linéaire gaussien, de loi marginale $\mathcal{N}(\boldsymbol{\mu}, \mathbf{W}\mathbf{W}^\top + \sigma^2\mathbf{I}_d)$ et de posterior gaussien exact ; au maximum de vraisemblance (Tipping et Bishop), $\hat\sigma^2$ est la moyenne des valeurs propres écartées et $\hat{\mathbf{W}} = \mathbf{U}_k(\mathbf{D}_k - \hat\sigma^2\mathbf{I})^{1/2}\mathbf{R}$, à une rotation $\mathbf{R}$ près ; quand $\sigma^2 \to 0$, on retrouve l'ACP de M12d | M25b |
| activation (fonction d') | activation function | une fonction d'une variable appliquée au score $z = \mathbf{w} \cdot \mathbf{x} + b$ d'un classifieur linéaire : seuil, sigmoïde, tanh, ReLU | M10 |
| actualiser, valeur actuelle, facteur d'actualisation | discount, present value, discount factor | ramener une somme future à sa valeur d'aujourd'hui : la diviser par $(1 + t)^n$ ; en M26, le facteur d'actualisation $\gamma \in [0, 1[$ : un gain reçu dans $t$ pas vaut $\gamma^t$ aujourd'hui ; c'est aussi la probabilité de continuer à chaque pas (M26 §4) | R5, M26 |
| adjoint (d'un nœud) | adjoint | $\bar{u} = \frac{\partial y}{\partial u}$ : la dérivée de la sortie d'un calcul par rapport à un nœud ; le mode inverse les calcule de la sortie vers les entrées, $\bar{u} = \sum_{u \to w}\bar{w}\thinspace\frac{\partial w}{\partial u}$ | M18 |
| affirmer le conséquent | affirming the consequent | le sophisme formel « $P \Rightarrow Q$ ; $Q$ ; donc $P$ » : non valide, la ligne « $P$ faux, $Q$ vrai » le réfute | M11 |
| AIC, BIC (critères d'information) | Akaike information criterion, Bayesian information criterion | $\mathrm{AIC} = 2k - 2\ln L$, $\mathrm{BIC} = k\ln n - 2\ln L$ ; le plus petit gagne ; le BIC pénalise davantage chaque paramètre dès $n \ge 8$ | M08 |
| aire algébrique | signed area | aire comptée positivement au-dessus de l'axe, négativement en dessous : c'est ce que mesure une intégrale | M02a |
| algorithme de Zermelo, algorithme MM | Zermelo's algorithm, MM algorithm (minorization-maximization) | pour un modèle de Bradley-Terry, avec $p_i = e^{\beta_i}$ : chaque balayage remplace chaque $p_i$ par $\frac{W_i}{\sum_{j \ne i}n_{ij}/(p_i + p_j)}$, puis divise les $p_i$ par leur moyenne géométrique ; un point fixe vérifie les équations du maximum de vraisemblance, et chaque balayage augmente la log-vraisemblance (Hunter, 2004 ; admis) : c'est un algorithme MM (minorisation-maximisation), qui maximise à chaque pas une fonction plus simple, située sous la log-vraisemblance et égale à elle au point courant | MB8 |
| algorithme EM, pas E, pas M | expectation-maximization (EM) algorithm, E-step, M-step | pour un modèle à variables latentes, alterner le **pas E** (la loi a posteriori de chaque latent aux paramètres courants : pour un mélange de gaussiennes, les responsabilités $r_{ik}$) et le **pas M** (les paramètres qui maximisent $Q(\boldsymbol{\theta} \mid \boldsymbol{\theta} _t)$ : pour un mélange, $\pi_k = \frac{N_k}{n}$, puis les moyennes et les covariances pondérées par les $r _{ik}$) ; sans régularisation, la log-vraisemblance ne baisse jamais (une montée par coordonnées de l'ELBO), mais l'EM peut s'arrêter sur un maximum local : on le relance depuis plusieurs initialisations | M25b |
| allométrie | allometry | une relation en puissance $y \approx c\thinspace x^a$ entre deux mesures d'organismes de tailles différentes : en logarithmes, une droite, $\ln y \approx a\ln x + \ln c$, dont la direction est celle de la taille ; retirer cette direction laisse ce qui ne tient pas à la taille, comme la corpulence | MB2 |
| analogie (entre des vecteurs), parallélogramme, requête, défaut | analogy, parallelogram, query, defect | « $\mathbf{a}$ est à $\mathbf{b}$ ce que $\mathbf{c}$ est à $\mathbf{d}$ » quand $\mathbf{b} - \mathbf{a} = \mathbf{d} - \mathbf{c}$ : les quatre points forment un parallélogramme ; pour chercher $\mathbf{d}$, on forme la requête $\mathbf{q} = \mathbf{b} - \mathbf{a} + \mathbf{c}$ et l'on prend le point le plus proche au sens du cosinus, en excluant $\mathbf{a}$, $\mathbf{b}$ et $\mathbf{c}$ (si $\lVert\mathbf{b} - \mathbf{a}\rVert \le \varepsilon\lVert\mathbf{c}\rVert$ avec $\varepsilon < 1$, alors $\cos(\mathbf{q}, \mathbf{c}) \ge \sqrt{1 - \varepsilon^2}$ : $\mathbf{c}$ serait presque toujours en tête) ; le défaut $\lVert(\mathbf{b} - \mathbf{a}) - (\mathbf{d} - \mathbf{c})\rVert = \lVert\mathbf{q} - \mathbf{d}\rVert$ est nul pour un parallélogramme exact | MB2 |
| analyse au premier pas | first-step analysis | conditionner sur le premier pas : depuis $i$, la chaîne va en $j$ avec la probabilité $p_{ij}$, puis repart de $j$ (propriété de Markov) ; elle donne les probabilités d'absorption (*absorption probabilities*) $\mathbf{h} = \mathbf{Q}\mathbf{h} + \mathbf{b}$, les durées moyennes (*expected hitting times*) $\mathbf{t} = \mathbf{1} + \mathbf{Q}\mathbf{t}$ et l'équation de Bellman | M26 |
| angle entre deux vecteurs | angle between two vectors | l'angle $\theta \in [0 ; \pi]$ tel que $\vec{u} \cdot \vec{v} = \lVert \vec{u} \rVert\thinspace\lVert \vec{v} \rVert\cos\theta$ | R9, M07 |
| angles principaux (entre deux sous-espaces) | principal angles | pour des bases orthonormées $\mathbf{Q}_A$ et $\mathbf{Q}_B$ de deux sous-espaces, les $\phi_i = \arccos s_i$, où $s_1 \ge \cdots \ge s_m$ sont les valeurs singulières de $\mathbf{Q}_A^\top\mathbf{Q}_B$, $m = \min(k_A, k_B)$ : des angles de $[0, \frac\pi2]$, qui ne dépendent pas des bases choisies ; pour deux droites, l'angle de M07 sans orientation, $\arccos\lvert\mathbf{u}^\top\mathbf{v}\rvert$ ; ils sont tous nuls si et seulement si le plus petit sous-espace est contenu dans l'autre | M25b |
| annulation (catastrophique) | catastrophic cancellation | la perte de chiffres justes quand on soustrait deux nombres presque égaux : l'erreur relative explose | M05a |
| antécédent, image | preimage, image | $f(x)$ est l'image de $x$ ; un antécédent de $y$ est un $x$ tel que $f(x) = y$ | R3 |
| apériodique (chaîne), période d'un état | aperiodic chain, period of a state | la période d'un état $i$ est le plus grand diviseur commun des longueurs des chemins de $i$ à $i$ dans le graphe de transition ; tous les états d'une chaîne irréductible ont la même, et la chaîne est apériodique si elle vaut 1 (une boucle $p_{ii} > 0$ suffit) ; irréductible et apériodique : $\boldsymbol{\mu}_0\mathbf{P}^n \to \boldsymbol{\pi}$ pour toute loi initiale (admis) ; une chaîne qui tourne sur cinq états, $0 \to 1 \to 2 \to 3 \to 4 \to 0$, a la période 5 : partie d'un état, sa loi ne converge pas | M26 |
| appariement des moments | moment matching | parmi les gaussiennes $q$, celle qui minimise $\mathrm{KL}(p \thinspace\Vert\thinspace q)$ a la moyenne et la covariance de $p$ ; pour un mélange à deux bosses séparées, elle les couvre toutes les deux et met beaucoup de masse entre elles | M25b |
| appariement trié | sorted matching | pour deux échantillons de même taille $n$, apparier le plus petit $x$ avec le plus petit $y$, le deuxième avec le deuxième, etc. : parmi tous les appariements $\sigma$, il minimise $\sum_i\lvert x_i - y_{\sigma(i)}\rvert$ et $\sum_i(x_i - y_{\sigma(i)})^2$ (∂ M27.14, par un argument d'échange) ; c'est le couplage des quantiles de deux lois uniformes sur $n$ points | M27 |
| application affine | affine mapping | $\varphi(\mathbf{x}) = \mathbf{A}\mathbf{x} + \mathbf{b}$ : une partie linéaire suivie d'une translation (en lignes, $\mathbf{x}\mathbf{W} + \mathbf{b}$ avec $\mathbf{W} = \mathbf{A}^\top$) ; la composée de deux applications affines est affine ; bijective si et seulement si $\mathbf{A}$ est inversible, et alors $\varphi^{-1}(\mathbf{y}) = \mathbf{A}^{-1}(\mathbf{y} - \mathbf{b})$ | M12a, M16 |
| application contractante, contraction | contraction (contraction mapping) | $f$ envoie une partie $\mathcal{D}$ dans elle-même, et il existe $q < 1$ tel que $\lVert f(\mathbf{x}) - f(\mathbf{y})\rVert \le q\thinspace\lVert\mathbf{x} - \mathbf{y}\rVert$ sur $\mathcal{D}$ : deux trajectoires se rapprochent comme $q^t$, la récurrence oublie son départ, et $f$ a au plus un point fixe dans $\mathcal{D}$, vers lequel tout converge (il existe si $\mathcal{D}$ est fermée et non vide : théorème du point fixe de Banach, admis) ; une jacobienne de norme au plus $q < 1$ sur une partie convexe suffit ; à ne pas confondre avec la contraction d'indices (M20) ; l'opérateur de Bellman d'une politique fixée est une γ-contraction pour $\lVert\cdot\rVert_\infty$ (M26) | M22, M26 |
| application linéaire | linear map, linear mapping | $f(\lambda\mathbf{x} + \mu\mathbf{y}) = \lambda f(\mathbf{x}) + \mu f(\mathbf{y})$ ; de $\mathbb{R}^n$ dans $\mathbb{R}^m$, c'est $\mathbf{x} \mapsto \mathbf{A}\mathbf{x}$, la colonne $j$ de $\mathbf{A}$ étant $f(\mathbf{e}_j)$ | M12a |
| approximation affine | linear approximation | $f(a + h) \approx f(a) + f'(a)\thinspace h$ : la courbe remplacée par sa tangente près de $a$ | R7 |

| arbre pondéré | probability tree | arbre des étapes d'une expérience, chaque branche portant sa probabilité : on multiplie le long d'un chemin, on additionne les chemins | R8 |

| argmax, argmin | argmax, argmin | la valeur de $x$ où une fonction atteint son maximum (son minimum), pas la valeur de ce maximum | R3, M05b |
