# 00 · Mise en place

| Fichier | Contenu |
|---|---|
| [INSTALL_LOCAL.md](INSTALL_LOCAL.md) | installation pas à pas sur ton ordinateur (Windows, Mac, Linux), ou dans l'environnement de workbookIA que tu as déjà |
| [COLAB.md](COLAB.md) | travailler sur Google Colab avec le dépôt dans Google Drive (`git pull`, sauvegarde) |
| [check_env.py](check_env.py) | vérifie ton installation : `python 00_setup/check_env.py` |
| [demo.ipynb](demo.ipynb) | démonstration : setup, `wbm.check` (un nombre, une fraction, une expression, un intervalle), SymPy, un graphique, `mymath` |
| [demo_solutions.ipynb](demo_solutions.ipynb) | corrigé de la démo ; montre comment les réponses sont enregistrées (`wbm.record`) |

Ordre conseillé : Colab d'abord (rien à installer), puis l'installation locale quand tu veux travailler hors ligne. Si workbookIA est déjà installé sur ton ordinateur, l'installation locale prend deux minutes : son environnement suffit.
